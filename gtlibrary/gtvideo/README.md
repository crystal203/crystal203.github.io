# GTVideo · 动画

入口为资源库的「动画」或 `index.html#view=video`。不依赖服务端数据库或新增 npm 包。

- 本地项目使用 IndexedDB 的 `GTVideo/projects`，每次数据修改排队写入；未完成保存时离开页面会触发浏览器保护。JSON 保存镜头数据、地图增删改差异（相对原始地图基准）、复制物块所需的资源描述、人物、关键帧、区间和主时间轴。内置素材仍从同一资源库加载，JSON 不包含全部原始贴图、Spine 和音乐文件。
- 主时间轴：镜头引用、入出点、图层、位置、速度、不透明度和音量；片段两端拖动裁剪，内部拖动移动，双击打开源镜头。截断和复制不会破坏源镜头。
- 镜头：单一主地图，可选原生人物；主画面直接使用 GTMap 的选取、移动、旋转、缩放、吸附和复制粘贴工具，编辑结果自动保存到镜头。删除实例的来源物件时会同时清理时间轴引用。跨页复制通过公共剪贴板传递，较小剪贴板也保存在本地以支持同源标签页；超过浏览器本地存储限额的大块复制仍使用当前资源库页面的内存剪贴板。
- 地块、物品、人物只有经过「实例化」才进入时间轴。画面点选可选择来源对象，实例化后才出现在轨道、相机跟随与 GTFX 目标选择中；移出时间轴会清除关联轨道和引用。普通地图对象不建立时间轴基线，未实例化 NPC 保持自身循环动画，导出时按循环动作直接采样。
- 选择人物资源会在唯一选中的基准对象处创建人物。GTAsset 角色场景的「复制到动画」可保留外观、装备、动作和表情。对象选择框也可编辑基础属性。
- 关键帧轨支持线性、平滑、保持；区间轨支持 Spine、表情、机关、GTFX、对白、跟随和音频。轨道可折叠、停用和筛选；面板可收起。
- GTFX 调用现有原生角色动作模块，提供主副目标对象与偏移、ScreenFX 开关、人物偏移及原生 Spine 轨覆盖。人物附着特效和场地特效保持不同的偏移规则。GTFX 的可用动作和资源完整程度沿用 GTFX 本身；不通过占位素材替代缺失原生效果。
- MP4 使用现有 Mediabunny + WebCodecs，H.264 视频、AAC 混音。导出按帧采样同一场景，按秒混音，镜头与项目均可指定导出起止秒数；从原时间轴采样并保留过渡及音频包络。支持宽高、帧率和视频码率及取消。编码要求本机或 HTTPS 页面、支持相应硬件/软件编码的 Chromium；画幅上限 3840×2160。最终 MP4 在内存中封装，输出总大小受设备内存限制。

## 模块

`model.js`：文档模型、校验、时间采样、剪辑运算与本地存储。
`scene.js`：共用 GTMap 场景、人物与机关，明确时钟采样、相机跟随及画面合成。
`special-effects.js`：原生 GTFX 动作及动态目标；复用地图 WebGL 上下文，按播放区间加载并提前预热，同一动作的运动目标变化复用 GPU 资源。
`editing.js`：对象姿态与相机关键帧记录；`number-scrub.js`：长按拖值、异步更新合并及单次撤销。
`audio.js`：GTAudio 引用、试听、播放调度及分段离线混音。
`export.js`：画面与音轨的 MP4 编码。
`apps/video/`：精简三栏编辑界面与两级时间轴。

GTMap 的 `videoBridge` 仅供显式时间采样和共享编辑工具，不改变地图页面默认的自动播放。普通 GTMap 的临时编辑与镜头快照分别保存。

已用独立临时 Chrome 配置定向检查：人物加载、关键帧、主时间轴截断、刷新恢复、地图导入、编辑回写、原生 Hana 动作的前后跳转采样，以及含视频和音轨的实际 MP4 编码。检查脚本保留在工作台目录，未添加大型测试依赖。

## 主画面编辑

- 默认打开镜头的自由视角，直接编辑地图和人物；Q/W/E/R 切换选取、移动、旋转、缩放，复制粘贴使用当前所选物件的位置，双击物件列表可聚焦。
- 「预览摄像头」才会将相机应用到时间轴，并暂时锁定画面里的物件和人物编辑。退出后恢复独立保存的自由视角。导出始终使用主摄像头和已记录的时间轴。
- 「设为主相机 ◆」在当前帧写入相机位置、目标、视野高度、近远裁切和投影方式；不会覆盖整个镜头的静态相机。对象仍须显式实例化才能记录轨道。
- 实例化时自动建立全部适用轨道。属性旁的「◆」同步该属性；「自动」写入对应轨道，关闭自动时修改仅保存在当前时间的编辑草稿中。「同步到时间轴 ◆」批量同步属性。未实例化对象仅修改静态地图或人物，继续普通循环动画。编辑草稿保存进项目 JSON；预览和导出只读取已同步的轨道。
- 连续数值输入框长按后左右拖动可实时调整；Shift 精调，Alt 加速。每次手势合并为一次撤销和一次持久化保存。移动和三轴旋转可直接由画面操作记录到当前帧。

## 轨道与局部更新

- 自由视角与预览默认使用 GTMap 的原生斜投影和固定 45°俯仰角，独立保留位置、目标和水平朝向；斜投影开关由相机区间轨道统一控制。
- 实例化时自动建立全部适用轨道，旧项目加载时补齐缺失轨道并保留原有编排。关键帧轨预置初始帧，状态轨预置初始片段；GTFX、对白和音轨保持空白事件区间。清空轨道保留轨道本身；选择轨道即可直接编排。位置、三轴旋转、缩放、透明度、速度使用关键帧；皮肤、Spine 动作、表情、朝向、子动画、装备、显隐使用状态片段。旧版项目的这些属性关键帧会在读取时转换为片段。
- 状态片段按最后一个已开始的片段持续取值，动作保持自身播放相位；尾部与中间空隙不回落到默认姿态，时间轴使用虚线显示延续区。对白、音频、GTFX 和斜投影等具有独立时长的事件遵循明确区间。
- 「轨道对象」直接进入单个对象的时间轴，不提供「全部对象」视图。从画面选择已实例化对象也会切到对应轨道；筛选与停用轨道分别工作。
- 对象实例化、移出时间轴、参数修改、轨道编辑以及相同资源结构的撤销重做均复用当前地图与 WebGL 画布。GTFX 只更新自身资源；更换主地图或需要变更资源结构的项目恢复才重建场景。

## 时间轴快捷操作

- K：在当前播放头截断所选区间；选择关键帧轨时在当前时间插入关键帧。状态区间的延续部分也可截断，Spine 区间截断后保留动作的源时间偏移。
- 「磁吸」控制关键帧移动、区间移动及两端裁剪。吸附目标为当前对象筛选范围内的其他关键帧、区间端点、播放头和镜头边界；蓝色辅助线显示吸附位置。按 Alt 可临时绕过，开关保存到本地。
- 磁吸目标在拖动开始时收集，拖动中二分查找邻近时刻；拖动只更新当前元素和辅助线，不重建时间轴或地图。
- 折叠轨道收进时间轴标题下方的紧凑条，不再保留空时间轴行。点击名称可选中，点击箭头可展开。

## GTFX 独立接管

- GTFX 片段提供位置、旋转、缩放、Spine 动作、朝向、装备、皮肤、表情、子动画、动画速度、显隐与透明度的独立接管开关，默认全部开启。关闭某项后该项使用人物普通轨道；开启后显示对应的片段设置。
- 特效场地以片段开始时的普通轨道姿态为基准。人物后续的位置差、旋转差与缩放比例通过相对矩阵叠加到原生动作，角色附着特效同步偏移，场地特效不随普通位置轨一起漂移。关闭变换接管时去除相应原生动作变换，保留普通轨道的变换。
- 不再创建 GTFX 偏移轨道。旧偏移轨自动转换为对应片段的内部偏移动画，原有静态偏移转换为片段的位置偏移。
- 对象装备、装备片段和 GTFX 装备统一使用槽位、中文名称/编号搜索、装备列表、卸下及恢复默认的界面，不需要编辑 JSON。GTFX 装备按角色支持的武器类型筛选。
- 秒数标尺保持为滚动表头；旋转、缩放、显示、皮肤、子动画、装备、动画速度默认折叠，首次读入旧轨道时应用一次默认布局，之后保留用户的展开选择。

- GTFX 世界绘制顺序转换为 GTMap 的材质队列与排序图层范围，人物、残影及世界特效使用同一排序规则；人物保留地图的贴地深度修正，避免后方透明图层覆盖角色而显得发透。原生动作淡入淡出与显式透明度设置仍保留。

## 手动同步与 GTFX 局部更新

- 非自动模式下，对象属性、关键帧数值和片段设置先进入独立编辑草稿。只有属性旁的同步按钮或明确的批量同步才写入轨道；播放、摄像头预览和导出读取已同步数据，静止编辑画面可查看草稿。
- 单项同步先提交当前输入框，并等待装备等异步编辑完成；同步后只清理该属性的草稿，保留其他未同步修改。关键帧或片段的属性面板提供「同步此属性 ◆」。
- 选中对象不会隐藏 GTFX 接管角色。原地图人物的渲染隐藏与对象的逻辑显隐分离，仍保留选取，不会把隐藏渲染写成显隐轨道。
- GTFX 的接管、偏移、朝向、皮肤及同类装备设置就地更新，保留地图画布、特效播放器和可复用的粒子模拟；更换角色、外观资源或动作模块时只更新对应特效层。卸下装备不会使已选择的原生特效动作消失。

## 局部求值与相机区间

- GTFX 接管开关仅显隐对应设置，装备、朝向及其他角色设置保留现有控件、搜索内容、焦点和滚动位置。装备切换更新原控件中的摘要和选中状态。
- 静止编辑时只求值受影响的实例及依赖它的特效；其他实例不重置位置、状态或重新采样骨骼。空闲画面复用已有缓冲，未实例化 NPC 仍按自身节奏循环播放。
- 相机跟随与人物跟随统一为位置关键帧的「跟随」轨迹段，不另建跟随轨道。区间左端点固定与目标的相对位置；相机右端点接住跟随结束时的实际位置和取景方向，再衔接后续动画。人物右端点仍使用自身坐标。
- 斜投影片段可开启或关闭 GTMap 原生投影，编辑视角与摄像头预览采用相同的投影状态；旧项目的斜投影关键帧自动转为区间片段并保留开关值。
- 相机近裁切、远裁切和斜投影轨道默认折叠，之后保留用户的展开选择。

## 跟随位置与批量选区

- 相机随目标的位移同时移动拍摄位置和视线目标，保持区间开始时的构图；原生斜投影补偿目标高度。跟随读取人物轨迹和 GTFX 接管后的真实位置。
- K 在相机跟随段内插入当前位置帧时会拆分跟随段并保持视线连续。旧版独立相机跟随区间与引用帧在加载时迁移为位置轨迹，保留端点构图。
- 时间轴空白处拖动框选关键帧和区间；Ctrl/⌘ 点选增删单项，Shift 点选同轨道的连续范围，Ctrl/⌘+A 选择当前筛选内已展开轨道的全部帧，Esc 取消。
- 选区可整体拖动，保持各帧间的时间差；边缘裁剪只作用于选中的区间。磁吸排除选区自身并约束整组选区在合法范围内。复制、删除、K 键截断/插帧支持混合选区，每次批量修改合并为一次撤销。

## 对象归属与真实发射位置

- 镜头时间轴只能进入主摄像头、一个已实例化对象、旁白或音轨。画面点选和实例标记均直接切换到对应对象；未实例化物件不显示其他对象的轨道。
- 默认轨道按对象能力建立。相机参数只归属主摄像头；旧项目中误绑到角色的相机轨道迁回主摄像头，保留原有数据。透明度轨道默认折叠，升级后仍允许用户自行展开并记住布局。
- 机关使用 GTMap 原生的控制器、状态、形态和节点显隐选项。对象属性中可预览并分别同步预建的状态组轨道；片段使用状态组和状态下拉框或显隐开关，支持最终状态及速度，无需填写组 ID。不同组使用独立片段时钟。
- GTFX 将目标坐标转换到角色包含位置动画、offset、旋转和缩放的实际坐标系。附着效果随角色移动，发射效果保留发射时的坐标系；命中效果读取目标的实际可见位置。世界空间粒子保留出生时变换，不随角色之后的 offset 整体漂移。
- 角色可见位置先按目标依赖求值，再用于各特效和相机，减少特效轨道排列顺序对瞄准结果的影响。帧求值缓存原生动作方案并复用地图、播放器及粒子模拟。

- GTFX 选择实例对象作为主/副目标后，停用对应距离偏移，仅按该对象的真实可见位置瞄准；初次加载和动作选择也使用同一目标坐标。距离值保留至切回距离模式，不再叠加默认 `(6,0,0)`。目标丢失时明确报错，不回退到距离目标。

## 帧剪贴板与链条

- 时间轴「复制 / 粘贴」及 Ctrl/⌘+C、Ctrl/⌘+V 支持关键帧、区间帧和混合多选。最早一项对齐当前播放头，其余保持相对时间和轨道属性；可粘贴到具有相同属性轨道的另一实例。重复粘贴生成新 ID，一次粘贴对应一次撤销。区间覆盖粘贴范围内的原内容，保留左右剩余内容及动作入点，尾部超出镜头则裁至镜头末尾。
- 双击关键帧定位到该帧；双击区间的左半边或右半边分别定位至起点或终点。普通点选保留帧元素，避免打断双击识别。
- Hook 类效果读取角色当前的相对变换与目标位置，钩头和链条一致更新；原生有限射程内的链节预先分配，距离增大时无需重建播放器即可延长，距离缩短时收起多余链节。

- 人物属性、表情区间和 GTFX 表情接管共用 GTAsset 的原生及高级表情选项。高级表情按当前朝向路由，背面隐藏面部叠层，重新转向后恢复；GTFX 复用表情资源与当前方向骨骼，按片段时钟采样叠层。

## 单次动作、Alt 复制与位置轨迹

- 关闭 Spine 片段的循环后，从片段入点播放一轮，再保持该动作末帧；拖动播放头可往返求值。动作、表情和子动画分别使用自己的起点、速度、入点与循环设置，子动画不再覆盖动作时钟。
- 按住 Alt 开始拖动关键帧或区间可复制到其他时间；支持混合多选，保留原帧、相对间隔、跟随引用及轨迹引用。复制拖动保留磁吸，按下后再按 Alt 的普通拖动仍可临时关闭磁吸。取消拖动不保留副本，整组复制只占一次撤销。
- 位置关键帧属性可为到下一个关键帧的段选择直线、跳跃或弧线；也可选中相邻两个位置帧后「设置轨迹段」。跳跃指定世界高度的顶点，支持两端高度不同的抛物线；弧线通过三轴偏移控制中点。轨迹连接明确的两个相邻帧，保存于 JSON；时间轴有轨迹段标记，自由编辑中显示路径，摄像头预览和导出隐藏编辑路径。位置采样、GTFX、相机跟随和导出共用轨迹求值。
- 对白使用在线玩 / GTMap 的原生九宫格气泡、气泡尾巴和中文字体，支持普通、喊话、思考及打字效果。角色对白锚定普通骨骼或 GTFX 骨骼的当前头部，旁白使用指定画面坐标；同一画布绘制适用于镜头预览、主时间轴和 MP4 导出。

- 原生对白尾巴按前后两张贴图及原始裁剪偏移组合，后片位于气泡后、前片衔接边框内侧；上下翻转保留对齐。修复的是气泡尾巴与边框层次，GTFX 的排序沿用原有规则。

## 气泡接缝、实例清理与动作混合

- 原生气泡的九宫格先按整数像素边界合成，再对整块面板绘制阴影，避免逐块阴影和亚像素拼接产生细线；共享 DOM 气泡也使用同一合成面板，按设备像素比缓存并限制缓存大小。
- 移出时间轴会清除该实例的轨道、逐属性草稿、帧草稿及运行时特效；删除位置跟随引用，清理其他 GTFX 目标及其草稿。取消当前选择后刷新对象下拉框，地图来源实体恢复为普通实体，不重载地图。
- Spine 动作区间增加「衔接 / s」，默认 0.15 秒，0 为直接切换；通过 Spine 原生 AnimationState 在前后动作之间混合。按片段时钟直接采样混合进度，保留各自动作的速度、入点及单次播放规则；往返拖动、GTFX 关闭动作接管时和导出使用相同结果。

## 镜头导出与独立音轨

- 在镜头中导出 MP4 时，以当前镜头画面及镜头内音频为范围；项目视图以主时间轴为范围。两者均可指定起止秒数，导出使用独立快照，结束后恢复编辑文档。
- 项目、镜头公共音轨以及每个角色实例的音轨集合都默认保留一条音轨。音频区排在视频 / 对象轨道之后；选择角色进入它的集合，也可通过「音轨集合」切回镜头公共音频。旧版对象音频保留原有归属与片段，不按音效名称新建集合。
- 「＋ 音轨」在当前集合增加空轨，轨道 × 或删除按钮可删除多余轨道及其片段；每个集合至少保留一条。添加音频时使用当前集合里选中的音轨或音频片段所在轨道，没有选中音轨时使用该集合的第一条。轨道属性可调整所属集合。隐藏的角色集合仍参与播放和导出混音。
- GTFX 音效映射仅作调查，见 `gtfx-audio-notes.md`；本次不创建自动音轨或添加特效音频事件。

## 角色相关音效导入

- 镜头中选中已在 GTFX 注册的角色，音频资源顶部优先显示该角色的原生关联音效，按普攻、技能、连锁分类；下方保留全部音频搜索。
- 关联依据角色原生动作的 SfxInfo、原生动作分类与外观覆盖，使用 GTAudio 默认资源并去除同名版本重复。只读取选中角色的元数据，不加载特效图像或创建播放器。
- 分类切换只更新关联列表；角色、外观或对应 GTFX 改变时刷新关联区。试听与导入沿用现有操作，导入使用当前集合选中音轨或第一条，位置为播放头；不自动创建轨道、不添加触发事件或安排时间。

## 波形、淡入淡出与配音

- 音轨行的「〰」或音轨属性的「波形」可选择显示波形。只对视口附近的音频按需解码，在 Worker 中生成多级峰值；拖动、缩放、改变音频入点只重绘可见像素范围，不重复分析。
- 波形峰值使用按音源哈希共享的内存缓存和独立 IndexedDB 缓存；源音频解码也复用并限制内存，峰值缓存限制条数和大小，不写进项目 JSON。关闭页面会结束波形 Worker。
- 音频片段可分别设置淡入、淡出时长，实时播放与 MP4 分段混音共用线性包络。两端时长超过片段时会按比例缩放到合法范围；片段拆分、覆盖粘贴和镜头裁剪保留原包络的进度。
- 角色相关音频增加「配音」，根据语音资源组与角色 / 外观资源关联，同时用当前原生角色来源的 Hero.OriginId 匹配数字资源组（如 watcher / yuna 均为 569），再通过相同语音编号关联其他语言，去除同语言同资源的版本重复，并显示语言。聚合角色按当前外观的原生来源选择编号，避免混入其他形态的配音。配音与特效音效共用试听、搜索和当前音轨导入，仍由用户自行对轴。

## 资源目录与收藏

- 地图选择复用 GTMap 的分类导航，支持逐级文件夹、上一级、面包屑、全部地图和分类 / 地图名 / 编号搜索，保留地图详情跳转。
- 人物列表从 characters 图集裁取缩略图，装备列表与当前装备从对应物品图集裁取缩略图；每张图集的图片、区域索引共用缓存，搜索和收藏不会加载人物模型或重建地图。
- 接入共享收藏：地图分类 / 地图、人物、装备、音频与其他页面使用相同收藏键，收藏优先排列，并可只看收藏。镜头与镜头内物件也支持本地收藏；动作、皮肤、表情、子动画、朝向、装备槽位沿用共享选项收藏。

## 镜头过渡与场景光照

- 主时间轴的镜头片段可设置入场 / 出场过渡与时长，支持无、黑场、白场、混合。同轨相邻片段共享切点设置；衔接过渡以切点为中心，重叠片段使用重叠范围，空白边界独立淡入淡出。过长的过渡按片段长度收敛，源镜头不足时保持端帧，不改变片段剪辑和音轨时间。
- 过渡复用少量合成画布，布局在编辑时更新；正常播放复用布局，过渡区间之外只绘制当前片段。预览和 MP4 导出共用合成逻辑。截断片段保留最外侧过渡，新切点为直接切换。
- 镜头属性可选择原始、明亮、昏暗、夜晚、暖光、冷光或自定光照，并调整亮度、光色与光色强度。统一处理地图、人物与特效的场景画面，对话框保持原色；光照调整不重建地图、不重设人物状态。设置随项目持久化并用于镜头 / 项目导出。

## 位置轨迹跟随

- 选中位置轨道的左关键帧，在轨迹中选择「跟随」并指定另一个实例对象。区间为左闭右开，位置为 `左关键帧位置 + 目标当前位置 - 目标在左端时刻的位置`；右端关键帧保留自身坐标，用于右端点及后续动画，不向右端坐标插值。
- 跟随、相机查询、GTFX 与导出使用同一确定性位置采样。目标可继续跟随其他对象；采样按对象与时刻共享缓存，局部更新只扩展到依赖对象，循环跟随会被拒绝。
- 非自动模式下轨迹设置先保留为预览草稿，点击「同步此属性」才写入轨道。K 在跟随区间内插帧时保留两侧跟随；复制粘贴和复制镜头维护目标引用，移出目标实例时清除其跟随引用。轨迹线按目标实际运动绘制，右端跳转不绘制为运动连线。

- 导出 JSON 时仅保存地图增删改与新增资源描述，清除地图操作历史和选择状态；旧版全量快照按原地图基准逐镜头压缩后导出。高级表情沿用 GTAsset 的预乘透明度混合，避免半透明边缘发暗。

- 左侧「物件」改为 items 图集物品资源，显示缩略图、名称和收藏；点击在基准对象坐标创建，可通过画面选取并实例化后编排位置、旋转、缩放与显隐。新增物品使用地图编辑胶囊增量保存，复制粘贴、JSON 和镜头复制沿用同一机制。
- 创建人物、物品或粘贴物件均须在镜头自由视角中唯一选中一个现存基准对象，禁止使用相机中心兜底放置；未满足条件时资源创建按钮禁用。
- 相机仅保留位置等必要轨道，原相机目标轨道迁入位置帧的取景方向。捕获主相机和同步位置同时记录视角，位置移动同步平移取景；跟随段固定左端构图，右端恢复对应位置帧的构图。

- 「锁定视角」将自由视角恢复到默认正向 45°俯视并禁止旋转，继续允许平移和缩放；不会写入相机轨道。Shift＋中键按起始拖动方向吸附到一个坐标轴，单次拖动只改变相机和取景目标的一项坐标。锁定偏好保存在当前浏览器，摄像头预览和导出仍采用已记录的视角。
- 拖动属性面板左边缘可调整宽度，分隔线支持方向键微调、Home 或双击恢复默认；宽度在刷新后保留。较宽面板下，顶端工具栏自动换行。

- 图集物品支持上下浮动、阴影和透明度。普通物品设置作为地图增量保存；实例化后自动建立对应轨道，浮动及阴影为状态区间，透明度为默认折叠的关键帧。关闭自动时，逐属性同步才会将草稿写入时间轴。物品使用原始图集的预乘透明度混合，避免重复乘 alpha 和额外的色彩空间转换。
- 主摄像头新增「镜头特效」区间轨道，支持渐入、渐出、振动、闪光、模糊、暗角，以及强度、颜色、振动频率/幅度等必要参数。多个区间可叠加；整幅镜头连同对白一起接受特效。振动按时间和种子确定性采样，预览与导出共用；截断、裁剪和粘贴保留原进度。中间画布按镜头缓存，仅在存在特效时使用。
- 光照亮度、光色、光色强度可在主摄像头下分别使用关键帧。光色按 RGB 插值；属性旁的同步按钮和自动模式沿用其他轨道规则。静态旧项目保留原光照作为初值，光照合成依然先于对白。

- 相机跟随结束帧自动求解前一段在终点前一刻的实际位置及取景方向，避免恢复旧帧值引发跳变。结束后保持此视角，或从此处插值到后续位置帧；连续跟随也以此视角接续。终点是动态引用，目标运动、跳帧、JSON 重新载入、预览和导出使用同一求值。终点位置在属性中显示为只读的「跟随结束位置」。

- 同一 GTFX 轨道允许重叠片段，粘贴时保留已有特效；重叠区间分行显示以便选取。每个角色同一时刻仅渲染一个本体，由最后开始的有效片段负责接管，起点相同时后放置的片段优先；其他片段只叠加世界特效及 ScreenFX，不重复显示角色，也不覆盖其真实位置。位置采样、相机跟随及 FX 目标使用相同的接管选择。
- GTFX 片段可开启「裁剪后继续播放特效」，默认关闭。开启后，在镜头范围内继续按原生时钟播放到动作/特效原生末尾，考虑入点和播放速度；角色动作接管仍仅限片段区间，延续部分只渲染特效。选项保存在 JSON 中，复制和预览/导出保持一致。

- 预览采用缓存画布完整绘制后一次提交，异步加载/准备特效时保留上一帧，出错也不清空显示画面。GTFX 按实际实例索引更新模块，复用已有粒子模拟；骨骼事件轨道每个原生模块只预处理一次，避免重复展开。非接管片段跳过角色网格绘制；预加载特效采用有限 LRU 缓存，减少往返跳帧时重复加载。

- GTFX 的「特效速率」、Spine 动作/表情/子动画的片段速度、角色动作速度、GTFX 接管动作速度、机关控制器、镜头特效、音轨和主时间轴镜头片段均允许负速率。负值从原生末尾倒放；大小决定速度，零值冻结动画（镜头片段除外，须非零）。播放偏移/入点按播放方向累计源时间，截断与裁剪保持源相位；Spine 的循环、一次播放和衔接仍然有效。
- 镜头片段倒放同时倒放其内部音轨并交换淡入/淡出方向。音频使用按解码缓冲区缓存的倒序副本，不依赖 WebAudio 的负 playbackRate；波形同步显示倒序和速率。预览与离线导出使用同一时钟。
- 镜头与项目属性各有「强制截取」和「截止 / s」。截止是独立播放边界，不删除关键帧、片段或修改原始时长；播放、音频事件、GTFX 延续和导出统一遵守此边界。关闭后恢复完整编排。镜头导出只应用镜头边界，项目导出还应用项目边界。
