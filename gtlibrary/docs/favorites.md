# 资源收藏

资源列表和常用资源下拉框旁提供 ☆ / ★ 按钮：☆ 表示尚未收藏，★ 表示已收藏，再点一次即可取消。点击星标不会加载资源、开始播放或更改当前选择。

收藏保存在当前浏览器的本地存储中，刷新、重新打开工作区后仍然有效；同一站点的页面与工作区会同步星标状态。清除站点数据会清除收藏。浏览器禁用本地存储时仍可在当前会话中使用。

## 排序规则

- 搜索先按原有关键词、分类及筛选条件匹配，再把匹配结果中的收藏项放在非收藏项前面，不会加入不匹配的资源。
- 收藏组与非收藏组内部保持原来的排序。排序发生在分页或截取前，因此后续页的收藏项也能进入第一页。
- 点击星标后立即更新图标，当前列表不会跳动。下一次搜索、筛选或重新打开下拉列表时应用收藏排序；取消收藏后同样在下一次查询恢复原顺序。
- 下拉框中的收藏项带 ★ 标记。下拉选项的资源编号、当前选中值和原始文本保持不变，不会因重新排序选错角色、图集或特效。

## 已接入的位置

统一搜索；Spine 角色、立绘和其他资源，装备物品、皮肤、动作、表情、子动画、朝向和装备挂点（含场景编辑器）；图集和切片；特效角色及效果；地图、地图分类、地图人物和原生片段；角色图鉴、形态、时装、立绘及专武版本；音频和资源组；在线玩关卡选择。

同一物品在装备列表和图集切片中共享收藏。统一搜索也识别相应模块资源的收藏。不同资源类别分别使用稳定的内部编号，避免同名资源互相影响。视图设置、播放速度、时间轴片段类型等操作性选项以及临时场景实例不作为资源收藏。

## 实现与验证

`core/favorites.js` 提供本地存储、分组索引、稳定排序及星标按钮，`shared/favorites.css` 提供共用样式。列表使用 `GTFavorites.order` 在分页之前排序；原生选择框使用独立星标按钮和 `option.label` 标记，保留 `option.value` 与 `option.text`。新增资源选择框可设置 `data-favorite-scope`，以 `data-favorite-id` 为选项提供稳定编号。

```sh
node tools/checks/favorites.cjs --unit
node tools/checks/favorites.cjs
```

浏览器检查需 Playwright 和 Chromium，也可设置 `PLAYWRIGHT_CHANNEL=msedge` 使用本机 Edge。检查覆盖保存/取消、刷新恢复、不匹配项排除、原始排序恢复、分页、下拉框值不变、装备与图集共享、跨页面同步、地图分类以及角色场景兼容。可通过 `FAVORITES_SCREENSHOT` 保存预览。
