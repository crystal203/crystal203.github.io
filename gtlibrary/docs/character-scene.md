# Character 场景与时间轴

打开 `index.html#view=spine&folder=character&name=hana`，或在像素动画页将目录切换为「角色」。默认使用「正常模式 · 单角色」，点击资源只替换当前预览；通过资源卡片中的「角色模式」选择「场景模式 · 多角色时间轴」进入编排。两种模式可随时切换，多角色、装备关键帧、播放头和轨道显示方式会保留。立绘、其他、自定义目录继续使用原有单资源预览。

## 放置与编辑

- 点击资源列表中的角色，将其添加到场景；可添加不同角色，也可重复添加相同资源。「复制角色」复制当前实例的属性、关键帧、装备和组件设置。
- 在画布或「场景角色」列表中选择实例。拖动角色修改位置；中键或 Alt＋拖动平移视图，滚轮缩放视图。「适配窗口」显示全部可见角色，「原尺寸」将视图恢复为每个资源像素一个画布像素。
- 位置 X 向右、Y 向上，单位为缩放前的资源像素。旋转使用角度，缩放 X/Y 分别控制宽高。视图缩放不会修改角色属性或关键帧。
- 每个实例独立设置动作、皮肤、朝向、表情、子动画、动画速度、循环及显隐。向左/向右使用侧面骨骼及镜像；非标准骨骼显示资源清单中的实际视角。
- 「上移图层」使当前角色覆盖前一层角色，「下移图层」反之。装备及组件透明度沿用原面板，设置只影响所选实例。
- 在同一像素动画页内切换目录会保留角色场景；离开该应用或刷新前，请先导出场景 JSON。

## 时间轴

先在 0 秒设置初始属性，再移动播放头。默认开启「自动关键帧」，在非零时间修改属性或拖动角色会在当前时间写入关键帧；已有轨道在 0 秒修改也会写入关键帧。关闭自动关键帧可修改实例的基础属性。属性右侧的 ◆ 按钮可以显式插入关键帧。

下方按角色及属性分轨显示关键帧。点击刻度或轨道空白处定位播放头，拖动可连续预览；双击轨道空白处可插入该时间的当前插值。点击 ◆ 后可调整时间与插值，拖动 ◆ 可更改时间，按 Delete 或「删除关键帧」删除。移到已有关键帧时间会替换该关键帧。

每个角色标题左侧的 ▾/▸ 可独立收起、展开轨道，右侧下拉框可选择「完整轨道」「简略 · 仅 Spine 动作」或「收起」。这些选项只改变编辑视图，其他属性和角色仍按原时间轴播放；显示方式随场景 JSON 保存。

位置、旋转、缩放默认线性插值，也可将起始关键帧设为「保持」。显隐、方向、皮肤、动画等离散属性保持到下一个关键帧再切换。第一帧之前以基础属性作为 0 秒起点，最后一帧之后保持最后的属性。

装备区的「装备」「删除」「脱下全部」同样参与自动关键帧：在非零时间操作会记录角色此刻的整套挂点装备，卸下后记录空装备。也可点击「◆ 记录装备关键帧」显式记录当前状态。完整视图中的「装备物品」轨可调整、删除这些关键帧；向前或向后定位会同步恢复物品及装备列表。关闭自动关键帧时修改基础装备。正常单角色模式的装备独立保存，不会覆盖场景中的装备。

动作、表情、子动画从各自最近的关键帧重新计时；同名动作也可通过新关键帧重播。速度变化按时间段累计，暂停、向前或向后拖动播放头均使用同一确定性采样。人物动画的循环与时间轴整体循环分别控制。

时间轴时长为 0.1–600 秒，不能缩短到已有关键帧之前。场景最多支持 100 个角色；实际流畅度取决于资源复杂度与设备。各朝向的骨骼数据预加载、实例按需创建，同资源不同朝向共享一套图集和纹理，多个相同实例共享解码后的数据，各自保留姿势与装备。

暂停场景按需重绘，未变更的角色不会重复采样或更新骨骼；隐藏角色跳过姿势计算。关键帧采用二分查询，动作速度使用缓存的分段累计时间；动画解析和下拉选项也会复用。普通属性编辑只校验当前值，不再复制整个场景。浏览器检查包含暂停稳定后零骨骼更新、零绘制调用，以及副本不重复请求图集/纹理的断言。

## 保存及动画导出

「导出场景」生成版本为 1 的 JSON，包含时长、有序角色列表、资源名、基础属性、属性关键帧、装备、组件设置和 `timelineView`。装备基础值保留在角色的 `equipment`，装备关键帧位于 `keys.equipment`，值为挂点到物品内码的映射（空对象表示全部卸下）。兼容之前没有装备关键帧或显示方式的版本 1 文件。「导入场景」校验并加载全部资源（含需要的装备图集）后替换当前场景；校验或资源加载失败时保留原场景。JSON 不嵌入纹理或骨骼数据。

原有 GIF、MP4、MOV、PNG 序列导出改为捕获整个角色场景，从时间轴 0 秒开始。勾选自动时长时使用场景长度，关闭后可导出场景开头的一段。导出范围与背景设置沿用原面板；「贴住模型」覆盖所有可见角色。导出完成后恢复原播放头位置。视频编码能力及透明背景限制与原有导出器相同。

## 验证

```sh
node tools/checks/character-scene.cjs --unit
node tools/checks/character-scene.cjs
```

浏览器检查需要 Playwright 与 Chromium，也可设置 `PLAYWRIGHT_CHANNEL=msedge` 使用已有 Edge。它启动临时本机服务器，验证真实角色资源、多实例属性隔离、关键帧插值、朝向/皮肤/显隐、骨骼姿势的反向采样、画布与关键帧拖动、JSON 往返、PNG 序列导出，以及目录切换。可设置 `CHARACTER_SCENE_SCREENSHOT` 保存截图。
