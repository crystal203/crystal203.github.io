# 地图微调

编辑仅影响当前展示，切换地图后清除，不写回原始地图。

- Ctrl+Z 撤回；Ctrl+Shift+Z 或 Ctrl+Y 重做，也可用工具栏按钮。保留最近 100 次操作，拖拽从按下到放开计为一次操作。支持位置、旋转、缩放、显隐、还原、机关状态及人物设置；机关和人物恢复逻辑状态后重播动画，不恢复历史视频帧。
- Shift+拖拽进行框选，Ctrl+Shift+拖拽追加选中。按投影包围框相交判定，可跨图层选取遮挡下方的物块；手动隐藏或关闭图层的对象不参与框选。原有同位置连续点击轮选和 Ctrl+点击多选保留。
- “隐藏物块”独立面板列出手动隐藏的对象，支持按名称、图层、坐标筛选，逐项勾选或选择当前列表后恢复。恢复保留微调位置，也可撤回。关闭整个图层的对象仍从图层面板恢复。
- 多选同一 tileset 中同名机关时，显示共同支持的状态和子组件，可同时播放状态转化、查看终态或修改显隐。不同状态显示“多个状态”；批量变化作为一次撤回操作。
- 宝箱等物品的等级对外显示为原始 Level+1，例如原始 0→Lv1、39→Lv40；原始数据和物品 ID 保持不变。

针对性验证覆盖整组平移/旋转/缩放的一次撤回与重做、隐藏两个物块后选择性恢复一个及撤回、两个 battlegate 批量切换和撤回、Shift 跨图层框选，以及主界面的 Ctrl+Z 与隐藏列表交互；没有运行全地图回归。
