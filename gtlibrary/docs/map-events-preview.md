# 地图走位与事件预览

主入口地图视图下方展开“走位与事件预览”。全部在浏览器运行，仍可部署 GitHub Pages，不需要 Node 或后端。

## 操作

- **原生片段**：fireworld_1 有“飞船着陆片段”，fireworld_5 有“封印大门开启片段”。选片段并载入，按播放、暂停，或拖动时间轴、调整倍速。镜头自动按可用画面高度取景。“停止并还原”恢复人物位置、显隐、动作设置、机关状态和镜头，释放临时剧情人物；可直接重新播放。
- **点选路线**：在“地图人物”列表选择人物，展开“自定义走位、动作与机关”，点“点选人物路线”，再在地图左键添加目的地。支持撤回最后一个点、清除、步行 / 奔跑、速度；点“生成路线时间轴”后播放。所填速度是世界单位/秒，Y 使用原生世界高度，区别于地图微调面板的双倍 Y 显示。
- **键盘走位**：选中人物后启用“键盘走位”；地图画面获得焦点，W/A/S/D 分别沿地图 +Z/-X/-Z/+X 移动，Shift 奔跑（预览速度 ×1.5）。再次点击关闭，整段走位可 Ctrl+Z 撤回。画面失焦会释放按键并切回待机；Ctrl+Z 也会先结束当前走位再撤回。为了防止两个控制器争用人物，时间轴正在控制该人物时，须先停止还原。
- **动作与机关串联**：设置事件时间，选中人物并在人物面板选择动作、朝向、表情和子动画，再“追加当前人物动作”；也可选择机关，选择动画组和目标状态后“追加所选机关变化”。同名机关多选会为它们在同一时刻追加变化。追加后点“载入时间轴”。门、火炬、炸弹花、灯等沿用已有原始状态控制器与动画；普通升降门使用组件参数，缺高度的仍按模型估算。
- **触发**：时间轴载入后选一个触发物件，用“使用选中物件”填入目标。交互方式点“等待触发”后再“执行交互”；接近方式会在键盘控制的人物进入指定水平半径时开始。可让人物走到门附近后执行一条只包含机关变化的时间轴。此半径由用户设置，不声称是原生 Region、完整进入或任务条件。
- **保存**：展开“时间轴 JSON”，可修改、载入、导入或导出编排。时间轴和微调不写入游戏存档。

人物与阴影总开关独立；单个人物可在详情中开关脚底阴影、调整透明度与倍率。人物资源按需共享解析与纹理，时间轴预热所需方向，默认不载入地图外的剧情预置。原生片段只在用户明确载入时引入它需要的预置 / 动态人物。

## 原生片段的依据与边界

`tools/gtmap/build-map-event-scenes.py` 离线生成 `gtmap/assets/event-scenes.json`，保留 Lua、地图及中文文本 SHA256；不直接执行反编译 Lua。

| 片段 | 原始依据 | 已还原 | 明确的预览处理 / 缺项 |
|---|---|---|---|
| 火世界飞船着陆 | `Quest/Main/FireWorld/Main/Section1.lua` 与对应 `CharacterPlacer/Main/Section1.lua` | 角色出场、pivot+offset、3 秒整体平移、1.3 秒等待、1 秒着陆、结束朝向、公主表情、中文对白 | 队长暂用男骑士，可改资源；跳跃用原高度/时长的抛物线；对白每句暂用 4 秒；未接音效、屏幕淡入、震屏 |
| 火世界封印大门 | `Quest/Main/FireWorld/Main/Section23.lua` 与 `stageeventcontrollers/FireWorld/Stage5.lua:gate_open` | 四人目标点与 1 秒走位、镜头、原脚本等待顺序、7.5 秒调用 native `open`，门体原片段为 2.8333333 秒 | 人物进入事件前的位置为预览布置；未接三个徽章特效、音效、震屏与任务条件 |

时间轴支持 teleport、move（绝对 / 相对路径，速度 / 时长，动作、锁定 / 自动朝向和结束朝向）、pose（动作、表情、子动画、皮肤、循环 / 单次）、jump、fade、shadow、visible、gimmick、camera、dialogue。等待用后续命令的 `at` 表达；同一时间的不同目标并行。不会运行战斗 AI、伤害、碰撞、自动寻路、小游戏控制器或持久任务系统；也未把全部 Lua 事件转换为预设。默认人物动画和地图背景动画仍独立播放；时间轴只冻结被它控制的角色和机关。

走位确实改变人物在地图中的坐标；跳跃只抬高骨骼，阴影跟随地面路径。当前路线按平面 / 显式 Y 插值，不检测高低地形、障碍、台阶和落地碰撞。原生跳跃函数的精确曲线及阴影相机补偿尚待继续核对。

## 时间轴格式

目标优先匹配此编排的 actor 挂点，再匹配地图物件 ID、人物挂点或 TileProp 的 FieldObject handle。找不到 / 匹配多个目标、未支持的指令、非法参数、重叠走位或未知机关状态会明确报错并还原，不能猜一个类似物件继续播放。

```json
{
  "version": 1,
  "map": "fireworld_5",
  "title": "走向封印大门",
  "duration": 6,
  "actors": [
    {"handle": "preview_hero", "resource": "princess", "position": [7.5, 0, 177]}
  ],
  "commands": [
    {"at": 0, "op": "visible", "target": "preview_hero", "value": true},
    {"at": 0, "op": "move", "target": "preview_hero", "points": [[7.5, 0, 180]], "duration": 2, "direction": "back"},
    {"at": 2, "op": "gimmick", "target": "s23_gate_1", "state": "open"},
    {"at": 2, "op": "dialogue", "text": "门打开了。", "duration": 3}
  ]
}
```

`pose` 支持 `animation / direction / expression / sub / skin / loop`；`move` 支持 `relative / speed / duration / animation / run / direction / lastDirection / endAnimation`；`fade / shadow` 使用 `value:0..1` 和 `duration`；`jump` 使用 `height / duration`。人物皮肤默认沿用其 prefab。

机关可用已核对的原状态名 `state`，或界面导出的 `group / value / still`，包括 `controller:<index>`、`custom:<index>`、`branch:<parent>`、`node:<id>` 及 `door:height`。`camera` 使用 `position / duration`，可加 `span` 指定可见垂直世界范围，或 `zoom`；这里的取景参数是查看器设置。

## 实现与定向验证

`gtmap/event-player.js` 维护有限指令、目标快照与独立预览时钟；跳转时从基线重算人物路径、动作时间、透明度、机关状态和门位移。机关动画、粒子与原生着色器时间跟随预览时钟。停止恢复初始状态；已有机关循环相位重新开始，不宣称恢复停止前每个粒子的瞬时相位。普通地图微调历史不写入每一帧，只记录用户键盘走位的一整段。

采用少量实际资源验证：princess + 原生阴影、battlegate 与 desert 升降门，检查了路径分段、透明度、暂停时门体真实矩阵不变、倒退后前进的矩阵一致、停止还原及缺目标报错；主界面实际载入两个火世界片段，封印门按真实挂点 `s23_gate_1` 找到 `open` 动画。未进行全库渲染或事件回归。


## 可视化编排与原生对白

地图的「剧情时间轴」使用人物/机关分组、位置/动作/对白等子轨。点击标尺定位，拖动片段移动，拖动两端改变时长；24 fps 是编辑吸附粒度，运行仍按秒采样。辅助轨道默认折叠，可勾选查看定位、显隐、透明度和阴影。可复制/删除片段、缩放或适配时间轴，属性栏编辑真实动作、朝向、表情、路径点、对白等。Ctrl+Z / Ctrl+Shift+Z 撤销/重做编排（焦点在时间轴）；地图微调保留自己的历史。地图路线会插入当前播放头，不再覆盖其他轨道。

原生片段载入后直接播放，可暂停、拖动播放头、停止并还原。具有 `duration` 的 `pose` 在片段结束后返回 `endAnimation`（默认 idle），`keep:true` 保留末姿。`dialogue` 支持 `target`、`bubbleType`（talk/shout/thought）、`bubbleDirection`、`typeSpeed`、`viewportPosition`、`position`、`height` 。对白按时长连续自动播放，不等待点击；旧文件的 `waitForClick` 也不阻断播放。画面气泡只显示正文，不显示说话人名字。播放时点击气泡或地图可跳过当前对白（拖拽、右键及多选修饰键不会跳过），但不再要求点击才能继续。气泡逐字显示并随人物及镜头更新，在画面边缘限制位置。富文本标签暂去除，`$name` 预览为「骑士」。

对白面板和箭头来自 `battle` 图集，按 `ui/stage/speech_bubble_new.prefab` 的九宫格参数切片（使用图集裁切帧，不把 sourceSize 顶部留白算入切片），原生文字颜色为 #312525。游戏的简体中文字体 `Tensentype_JiaLiDaYuan_J` 从本地 APK 内 `assets/AssetBundles/Android/fonts/zh-hans` 的 Font.m_FontData 提取，完整字体 3,948,628 字节，在对白出现时由浏览器加载。来源、SHA-256 与切片资料见 `gtmap/assets/dialogue/provenance.json`。不是 Unity Editor 自带字体。

飞船着陆片段按原脚本保持飞行时 idle 的姿势、3 秒平移、1.3 秒等待及 get + 跳跃；补入六句中文对白及后续惊讶跳跃，未展开选择分支。对白人工预留 4 秒自动播放，跳跃曲线为近似；不能把预留时间当作游戏原生对白时长。修复预览的 alpha 仍乘以地图初始化 alpha=0 导致无法显现的问题；子动画轨也跟随预览时间采样。

新增水世界三位引导者的开场，使用原始 s1_intro_pos、动态 NPC 配置、渐显时间、19 句对白次序。原生开场 fairy_tail 骨骼特效、屏幕圆形转场及音效仍未接入。

另有 14 张地图的 309 条独立原生对白/动作调用，按地图读取 gzip 文件。生成器只接纳明确的 available_stage_names、唯一 get_character 挂点、该地图实际放置且资源可解析的人物，以及字面量的对白键/动作/表情。它们显示为「原生对白与动作 · 独立摘录」，每条单独排练，不推断 Lua 的分支和运行顺序，不宣称还原完整任务。索引记录原脚本与中文表 SHA-256；完整剧情可选手工核对片段或下述世界22批量转换入口；后者逐条标明覆盖限制。

离线生成：`python tools/gtmap/build-map-event-scenes.py`，`python tools/gtmap/build-native-dialogue-clips.py --source E:/GTFiles`。网站运行只依赖静态文件及浏览器，不需要 Node。

对白资源可用 `python tools/gtmap/build-dialogue-assets.py --apk <本地APK路径>` 重建；依赖离线已有的 UnityPy/Pillow。


### 操作与演示布局

操作布局压缩导航、工具栏和次要面板；时间轴打开时临时收起图层/导出/操作提示，时间轴内容独立滚动。工具栏的「演示布局」会收起主资源库导航、地图目录、编辑面板与选中框，使地图充满整个窗口，并继续播放当前编排。默认点击播放自动进入演示布局；取消「演示播放」可在操作布局中播放，该选择会保存。演示布局仍可选择当前地图的原生片段并载入播放，左上保留暂停/停止，右上「操作布局」或 Esc 返回编辑；原来的选中框、事件标记及路线显隐会恢复。

对白框使用原生 UI 和中文字体；按完整文字预先固定尺寸，按箭头中心而非左上角对齐，以 `[base]head` 骨骼随动作定位，缺少骨骼时回退到人物高度。优先放在人物头部上方，边缘调整左右，顶部空间不足时移到下方，逐字显示不会使气泡伸缩。暂未完整模拟原生富文本、多个同时气泡和所有脚本中的显式偏移。


## 世界22批量剧情与交互分支

扫描 109 个源脚本，当前生成 8 张地图的 367 条分支轨迹、227 个方法入口（包含辅助方法，绝非 227 段完整剧情）。新增 `tools/gtmap/build-world-native-scenes.py` 与 `native-scene-recorder.lua`，离线读取 FireWorld 的任务脚本及 Stage1–6 控制器，生成静态 gzip 时间轴。原脚本只在无文件、网络、宿主对象访问的 Lua 环境内记录，设有指令、调度次数、时长及分支数量限制；网页不执行 Lua，也不需要 Node。离线生成需 Lupa，使用已记录的真实 Spine 动作时长（`tools/gtmap/evidence/world22-animation-durations.json`）。

源脚本 SHA-256、各入口/分支的完成或中断情况、未实现调用、资源缺失与估计动作时长，逐项记录在 `gtmap/assets/native-world-scenes/world22-coverage.json`。下拉列表每个方法只显示一个入口，分支由画面上的选项切换。中断片段和部分还原明确标注；入口统计包含辅助方法，不能当作完整剧情数量。主地图与温泉、飞龙支线按需读取独立文件。

`Main/Section1:start_scene` 按原始布置组从飞船上的空中段开始，包含后续着陆、走位和三个选择节点；空中 theatre_sky 背景特效尚未渲染。此前人工核对的 `s1_landing_scene` 保留为短片段。原 NPC 配置决定动态人物模型、装备与可验证的中文名称，缺少中文预设的名字和剧情名保留内码。默认主角采用 `knight_male_2` 的原资源引用 `knight_male_4:knight_male_2`；当前导出骨骼只有 default 皮肤时会明确提示外观回退，不宣称已还原缺少的皮肤。

播放前先采样初始人物位置、动作和镜头，清除 OrbitControls 尚未完成的平移/旋转惯性；重新播放也立即应用起点，不从浏览位置飞过去。动态人物放入 NPC 图层，并参与人物距离排序、原生 SortingLayer/SortingOrder，修复骑士被飞船覆盖的情况。idle、表情与子动画都持续用事件时钟采样。

动作沿用 scene_util 的原生默认 loop/count/scale/keep_anim/remove_after 参数，次数和速度以真实骨骼时长换算。非循环 `set_anim` 保留末帧，异步动作、限定次数或 remove_after 在结束后回到 idle；明确 keep_anim 时保留。预览为有限时长，播放完自动暂停，不自行循环剧情。

`choice` 包含 ordinal、options（text/key/tendency/enabled）。播放头停在尚未作答的节点；播放按钮与点击对白都不会绕过选择。选项选择相应原始分支并从该节点继续，保留事件前的基线以便停止还原。原生事件导出会附带同一入口的分支，导入后仍能选择。任务/存档相关谓词未模拟，覆盖报告会提示，不能将预览选项可用性视为真实存档条件。

选项面板引用原 `ui/stage/Answer Choice.prefab` 的按钮、选中边框和五种倾向图标，直接切取 main_ui 图集；九宫格边界来自原 main_ui.prefab（btn_white 8、main_line_r16 19），使用游戏中文字体。来源哈希与帧坐标存于 `gtmap/assets/native-choice/source.json`。尺寸按当前画面缩放；已按 prefab 恢复 forced 的红色底（1, .44852942, .44852942），normal 沿用 choose_util 声明的白色默认值，禁用态和脚本显式 Color32 也可着色。intellect/brutal/mercy 的运行时底色尚无可靠证据，暂用白底并在报告标记，不推测配色。屏幕淡入/淡出支持黑幕透明度，圆形转场暂近似为淡入。

未恢复游戏存档、任务进度、战斗 AI、寻路碰撞、音效、全部特效 prefab、完整演出肖像和所有任务条件。没有运行每一条生成片段的完整视觉测试；定向检查覆盖起点即时定位、pilot idle 骨骼变化、骑士/飞船排序、非循环末姿、选择暂停与分支续播、停止还原及完整开场载入。


### 对话、触发入口与统一时间轴

感叹及思考气泡恢复九宫格中心填充。显式 viewport_pos、scale 进入对白命令；完整肖像仍未渲染，文本使用气泡呈现且在覆盖报告标注。选择期间保持剧情时间、人物位置和镜头不动，循环身体/表情及机关动画继续采样；非循环动作保持其当前姿态。暂停按钮仍为普通暂停。

路线绘制、动作与机关、触发入口共用时间轴的属性侧栏，移除独立「地图路线与触发设置」面板；路线可以写入新位置轨，也能覆盖选中人物的现有走位片段。触发目标、方式、半径存入 plan.trigger，通过零时刻的触发入口轨道访问，支持编排撤销和 JSON 导入导出。屏幕转场和分支选择有独立轨道，动作、表情循环、皮肤、速度、末帧、排序、气泡参数可在属性栏编辑。原生分支由各自独立时序生成，修改一个分支的选择时间不会自动重编全部分支；需要同步调整其他分支。

加载阶段先用遮罩覆盖画面，人物/镜头和所需朝向就绪、采样后才显示。Main/Section2:steam_princess_zone_event 使用地图 s2_steam_princess_event_zone 的原始位置作为入场参考，队伍队形为近似（实际游戏由玩家进入触发区的位置决定）；保留随后的原生 1.5 秒短距离走位。其他独立入口遇到无原生起点且首段走位横跨地图时，使用邻近触发区或首目的地布置，并明确标记 estimated standalone entry。镜头从局部场景开始，布局改变时重新应用当前镜头视野。
